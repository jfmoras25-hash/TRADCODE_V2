# Poses de referencia de Eidos

Los 16 JSON de esta carpeta son copias sin cambios de la [biblioteca pública de Eidos](https://lanixiligan.github.io/eidos/), el editor usado para elaborar las poses de Sema. Sema enseña dactilología de la lengua de señas estadounidense (ASL). Se verificaron los nombres y las huellas de los archivos contra el [repositorio de Eidos](https://github.com/lanixiligan/eidos/tree/main/letters). La licencia original acompaña a los archivos.

- Disponibles en esta descarga: F, G, H, I, J, K, L, M, O, P, R, U, V, W, Y y Z.
- N, Q, S, T y X aparecen en el índice público, pero sus archivos devuelven HTTP 404. Ñ no figura en el índice.
- El catálogo que consultan las lecciones de TRADCODE está en `../index.json`. Apunta a los cinco archivos preexistentes de A–E y a los 16 originales de esta carpeta. Las lecciones identifican la procedencia ASL de estos 16 modelos. Los ejercicios de cámara siguen evaluando LSC.
- Las poses de J y Z incluyen cuatro pasos de movimiento cada una. El botón **Reproducir movimiento** usa la secuencia y la duración de cada paso del JSON original.
